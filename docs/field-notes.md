# 平台技术笔记（Field Notes）

公开笔记记录页面机制、故障判据和可复用配方。课程实例、个人进度、成绩、签名地址和运行时间线只留在本地运行记录。
详细选择器见 `knowledge/chaoxing.md`、`knowledge/icourse163.md`；运行策略见 `SKILL.md`。

## 目录与任务点

- 目录有 `.posCatalog_select` 与 `.chapter_item[onclick*=toOld]` 等布局。等目录行渲染完成，再从页面现有入口进入节点。
- 课程卡片的 `enc`、`ckenc` 等参数会轮换；从课程卡真实点击进入，不复用旧签名链接，也不拼 `studentstudy`/`cards` 直链。
- 卡片可按需加载「学习目标 / 视频 / 章节测验」部件。先点当前节点的视频页签，再确认播放器属于当前章节；上一节残留播放器不能当作本节资源。
- 一节可能含视频与测验两个任务点，也可能各自独立成节。阅读、问卷等无任务点内容可能另计成绩，按用户任务范围处理。
- `ended` 是播放器状态；完成判定还要核对平台标记与新加载的课程总数。目录角标可能是加载时快照，记录传播也可能延迟。
- 补分扫描用 `forceIdx` 白名单。树计数不能单独证明视频已完成，也不能代替测验完成核验。

## 播放、焦点与恢复

- `preload="none"` 时，先用官方播放控件起播，再读取时长与媒体资源。
- 旧播放器会因焦点丢失暂停；新播放器行为可能不同。以 `currentTime` 是否持续推进判断健康，不能仅看 `paused`、`hasFocus()` 或 `visibilityState`。
- IAB 切换或认领别的标签可能使当前视频停摆；维持单标签监督。系统锁屏、熄屏与最小化的行为不同，按当前环境核实。
- 锁速课接受 1x。`scripts/keepalive.js` 会改速率，不适用于锁速课；使用只读 `scripts/keepalive.beacon.js`。
- 静默暂停要跨帧找 `.vjs-play-control`，并回读时间推进；计数器增长不能证明点击成功。
- 断网、媒体 `error=2/3` 或页面重载后，先确认当前资源与平台保存位置，再用官方控件恢复。页面重载可能使本段从头播放，不能假设本地已看时长被累计。
- 信标脚本保持只读，勿在其中加静音操作；某些环境下静音会触发浏览器省电暂停。静音按运行手册在起播步骤处理。

## 巡检与调用边界

- 信标记录时间、暂停、结束、弹题、答错滞留与 idle。弹题或停摆信号出现就回到短周期处理。
- 单次工具调用有硬上限；扩大调用内采样间隔不能突破上限。长等待与检查分开，等待后单次读信标；具体预算见 `SKILL.md`。
- 未知结构最多试两种已知配方，再记录技术现象并按 fallback 处理。

## 弹题与章节测验

- 先探控件骨架。旧弹题必须点 `input[type=radio]` 并回读 `checked`；有些测验页则必须点 `li[qid]`。
- 弹题答错层可能长时间滞留，也可能自动消失；静态「回答正确」文案不是判定。按当前播放器的可见控件与任务点分别核验。
- 混淆字体按页随机，跨页码位映射不可靠。优先当前页明文、canvas 渲染或截图 OCR；映射表只作页内辅助。
- 图形选项可将页面提供的选项图片绘成网格再读；同时保留选项顺序与内部 token。
- 提交前收集 `qid` 与 `input[name^=answer]` 映射；提交后这些字段可能消失。显示字母与 `span[data]` 可能不同序，按内部 token 回读校验。
- 完整提交流程是「全部读完 → 全部作答 → 核对 → 提交 → 可见确认层确认」。关闭浮层的工具只能在开始前使用，以免把提交确认层一起关掉。
- 重做会预填上次作答。用精确集合修正，既补选也取消旧选项；不能只追加正确项。
- 重做额度、正解可见性与计分方式因课程而异。先探测结果页和重做入口，按现有授权及 `SKILL.md` 策略处理；无正解或无入口时不盲目重做。
- 成绩不能代替任务点判定。一次附件可能限制打开次数，先完整读题，勿空卷提交或反复重开。
- 仅已完成节点允许按官方控件 seek 补看漏网弹题；不以 seek 冒充未完成节点的真实播放。

## 风控与登录

- 日上限模板可能常驻 DOM；用可视几何判断是否真的触发。验证码、日上限、多终端提醒等按运行手册停止条件处理。
- 避免短时间连续跳页；跳页间隔至少 4 秒，每轮最多 10 次。跨源 iframe 使用受支持的 frame 通道，不把访问失败误判成页面缺内容。
- 登录成功需核对课程页骨架与账号状态，不能只看 URL 离开登录页。凭据仅按本次用户授权传递，不写入公开笔记。

## 中国大学MOOC

- 内容按周发布，Runner 应重新扫描课件矩阵、跳过 learned，不能硬编码旧内容清单。
- 测验先读限时、限次与有效提交次数；结果页正解和分数可能由教师隐藏，无修正依据时不盲目重做。
- 页面可能有多层同名确认框；按可见层定位。遇到服务端节流提示先停止，不能用并发重试放大请求。
- 同一 profile 同时打开多个 persistent context 可能产生僵尸会话；维持独立 profile 与单执行器。

## 新笔记格式

记录触发条件、页面结构、可见现象、最小复现步骤、处理方法和未验证范围。公开内容使用占位参数；可识别课程、账号、成绩与时间线保存在忽略的本地记录中。
