# 验证范围与发布边界

版本：2.0.0-preview.9。测试和实战记录分别说明能力，不以工具返回成功代替平台验收。
公开版本仅保留匿名能力结论；个人运行材料、原始题目、字体、截图、课程实例和逐节点记录不随包发布。

平台可在正确后直接移除弹题，也可能在提交中保留上一答提示；结果不明先核对，不重复提交来测试。

## 离线检查

离线测试覆盖列表采集/对比、题面与字体批次、OCR 回退、媒体/弹题身份闸门、单次提交回执、结果态、观察器清理、预算以及打包边界。

```text
node tests/test_codex_mute_video.mjs
node tests/test_codex_observe_video.mjs
node tests/test_codex_video_quiz.mjs
node tests/test_codex_video_transaction.mjs
python -m unittest discover -s tests -p test_packaging.py
python -m unittest discover -s tests -p test_codex_usage.py
```

依赖和可选 OCR 运行时用 `scripts/doctor.py` 检查。合成 DOM、离线 OCR、文件哈希及 PASS 均不能证明真实平台计分、字幕真实性或原生窗口状态。

## 实战验收

1. 核对当前账号别名、课程、章节、附件、媒体完整路径与单执行器归属。
2. 新视频重新静音，通过真实平台控件起播，观察两段时间推进。
3. 只处理当前题面及已授权测验；检查显示选项、真实选中态、保存反馈和提交结果。
4. 视频结束后读对应完成标记；章节测验后读平台结果；刷新目录核对保存。
5. 后台、最小化、锁屏及进程退出分别记录。没有现场证据时保留未验证。

## 开销证据

调用次数、返回字节、模型输入/缓存/输出 token、播放时间与失败恢复成本分别记录。
本地用量工具只读取显式选择且身份匹配的会话中的计数字段。输出回读消耗对应后续模型请求，不能用最近一条计数错误归因。
受新用户输入或其他任务干扰的样本标为受干扰；样本差异不能直接换算为订阅额度或整课节省比例。

## 公开导出检查

公开包按白名单生成，不复制开发仓库的 `.git`、本地索引、凭据、浏览器配置或运行证据。
发布前检查姓名、学校、班级、学号、账号、密码、邮箱、手机号、个人目录、会话参数，以及提交作者元数据。
通用模式不能识别所有个人信息，敏感词名单与人工审阅仍是必要步骤。保持 MIT 许可及合法公开来源署名。
